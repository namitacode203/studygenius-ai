# StudyGenius AI 🧠✨

Welcome to **StudyGenius AI**, a state-of-the-art intelligent learning companion designed to revolutionize the way students interact with educational materials. Built with modern web technologies, StudyGenius AI automatically processes study materials and generates insights, summaries, interactive quizzes, and intelligent flashcards to enhance comprehension and retention.

---

## 🌟 Key Features

*   **📄 Intelligent PDF Processing:** Seamlessly upload course materials and lecture slides. The system securely processes the documents to extract key concepts.
*   **📝 Automated Summarization:** Instantly generate concise, accurate summaries of lengthy documents, saving hours of reading time.
*   **❓ Dynamic Quiz Generation:** Automatically create interactive, multiple-choice quizzes tailored to the uploaded material to test knowledge in real-time.
*   **📇 Smart Flashcards:** Generate beautifully animated 3D flashcards for spaced repetition and active recall learning.
*   **💬 AI Study Chat:** An integrated conversational agent that acts as a 24/7 tutor, ready to answer questions and clarify complex topics based on the course material.

---

## 💻 Tech Stack

StudyGenius AI is engineered with a modern, high-performance tech stack to ensure a fluid user experience:

*   **Framework:** [Next.js 15](https://nextjs.org/) (App Router) for Server-Side Rendering and optimal performance.
*   **Language:** [TypeScript](https://www.typescriptlang.org/) for robust, type-safe code architecture.
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) for a fully responsive, utility-first design system with Glassmorphism aesthetics.
*   **Animations:** [Framer Motion](https://www.framer.com/motion/) for fluid, professional micro-interactions and layout transitions.
*   **Icons:** React Icons (`react-icons/ri`) for a clean, consistent visual language.
*   **Charts:** Recharts for dynamic data visualization in the student dashboard.

## 🚀 Getting Started

To run this project locally on your machine for demonstration or development purposes, follow these steps:

### Prerequisites

Ensure you have the following installed on your system:
*   [Node.js](https://nodejs.org/) (Version 18.0.0 or higher recommended)
*   npm (comes bundled with Node.js)

### Installation

1.  **Clone the repository** (or download and extract the ZIP file):
    ```bash
    git clone https://github.com/namitacode203/studygenius-ai.git
    cd studygenius-ai
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```
    *(Note: This project relies on standard npm packages. Please ensure you are connected to the internet during this step).*

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **View the application:**
    Open your browser and navigate to [http://localhost:3000](http://localhost:3000).
